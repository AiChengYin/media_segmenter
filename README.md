# MediaSegmenter (音视频分割/合并工具)

这是一个基于 Python 和 `customtkinter` 构建的轻量级音视频处理桌面应用程序。它可以帮助您轻松地将长音视频文件分割成多个片段，或者将多个媒体片段无损/重新编码合并成一个完整的文件。底层依赖 `ffmpeg` 进行媒体处理。

## 主要功能

1. **媒体分割**：
   - 将单个音视频文件平均分割为指定数量的片段。
   - 支持设置前置重叠时间，确保片段之间的平滑过渡（例如用于分段转录时不丢失上下文）。
   - 自动获取媒体时长，快速无损处理。
2. **媒体合并**：
   - 快速将一个文件夹内的所有音视频片段按顺序合并为一个文件。
   - 优先尝试无损合并（直接 `copy` 编码），如果失败则自动尝试重新编码合并。

## 环境要求

- Python 3.8+
- 系统必须安装 [FFmpeg](https://ffmpeg.org/) 并且已配置到系统环境变量（`PATH`）中。

## 依赖安装

在使用或打包前，请安装必要的 Python 依赖：

```bash
pip install -r requirements.txt
```

## 运行与打包

### 源码运行
直接运行主程序：
```bash
python main.py
```

### 独立程序打包 (Windows)
提供了一个自动化的 `build.bat` 脚本用于将应用打包成单独的 `exe` 可执行文件。
1. 双击运行项目根目录下的 `build.bat`。
2. 脚本会自动安装依赖并使用 `PyInstaller` (通过 `build.py`) 进行打包。
3. 打包完成后，您可以在 `dist` 目录下找到生成的 `MediaSegmenter.exe`。

## 注意事项
- 处理大量或非常大的媒体文件时，进度条可能需要几秒钟响应，请耐心等待。
- 确保您的电脑已经正确安装了 `FFmpeg`，否则程序在点击处理时会提示相关错误。
