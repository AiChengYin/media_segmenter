# MediaSegmenter (音视频处理工具)

基于 Python + `customtkinter` 构建的轻量级现代化音视频处理桌面应用，底层依赖 `FFmpeg`。采用了「纯白秩序工坊 · Modern Clean Light」原生视觉设计，0 额外运行开销，纯净 Windows 沙盒免安装开箱即用。

---

## 🌟 核心特性与功能

### 1. 音频处理
- **音频分割**：
  - 将单个音频文件平均分割为指定数量的片段，支持前置重叠时间平滑过渡。
  - **保持源格式 & 极速无损优先**：默认优先采用 `-c copy` 无损秒级切片，保留输入文件扩展名（如 `.wav`、`.flac`、`.m4a`、`.mp3` 等）；若原容器不支持无损分段则自动平滑回退重编码。
- **音频合并**：
  - 一键合并文件夹内所有音频片段，使用系统隔离临时目录，杜绝文件残留。
  - 完美支持包含空格、中文及单引号 `'` 的特殊文件名。
  - 支持普通合并（优先无损）与“安全合并模式”（统一转码为高保真标准音频后再合并）。
- **音频截取**：
  - 精确截取指定时间区间的音频，支持秒数格式（如 `37.30`）或时分秒格式（如 `00:01:15.50`）。
  - 优先无损极速截取，失败自动回退高质量重编码。

### 2. 视频处理
- **视频分割**：支持多段均分与重叠时间设置，优先无损分割，失败自动回退重编码。
- **视频合并**：按文件名排序合并目录下所有同类视频片段，安全转义与防自吞噬合并。
- **视频截取**：
  - 选择视频文件后自动读取并展示总时长、画面分辨率与文件大小。
  - 输入起止时间快速截取，严格校验时间逻辑（结束 > 开始，不超过总时长）。
  - 优先无损截取，失败自动重编码。

### 3. 全环境兼容与沙盒原生适配
- **开箱即用（Zero-Dependency）**：单文件打包内置完整 FFmpeg、FFprobe 及核心编解码动态库，**在全新纯净 Windows 或 Windows 沙盒（Windows Sandbox）中无需配置任何系统环境变量即可直接运行**。
- **高 DPI 与自适应布局**：支持窗口自由伸缩（最小尺寸安全保护），自适应屏幕分辨率与缩放比例。
- **跨语言安全字体**：内置字体降级回退机制（优先微软雅黑，自动回退黑体、Segoe UI、Arial），在中英文及精简版系统上排版一致。
- **健全的异常与日志保护**：在无控制台（`--windowed`）模式下防止流输出崩溃，任务失败直接展示精准错误摘要，彻底告别空洞的“请查看提示”。

## 🛠️ 运行环境要求

### 源码直接运行：
- Python 3.8+
- 安装依赖：
  ```bash
  pip install -r requirements.txt
  ```
- 宿主机已安装 FFmpeg 并加入 `PATH`（或放置于源码同级目录 / `ffmpeg_bin` 目录下）。

### 单文件免安装 EXE：
- 任意 Windows 10 / Windows 11 环境（包括 Windows 沙盒）。
- **无需安装 Python，无需预装 FFmpeg，双击即用**。

## 📦 打包为单文件 EXE

项目提供了自动化构建脚本，支持自动探测宿主机 FFmpeg 二进制及其依赖动态库，并内嵌打包为单文件 `dist/MediaSegmenter.exe`：

### 方法一：使用 PowerShell 一键构建（推荐）
```powershell
.\build.ps1
```

### 方法二：直接执行 Python 构建脚本
```bash
python build.py
```

构建完成后，可在 `dist/MediaSegmenter.exe` 获取最终产物。
构建脚本会自动排除无用的 `ffplay.exe`，精简产物体积。

---

## 💡 注意事项

- **单文件首次启动**：PyInstaller 单文件（`--onefile`）在沙盒或纯净系统中冷启动时，会短暂解压内置的 FFmpeg 运行库至系统临时目录，存在约 1~2 秒的正常初始解压时间，随后即进入秒级响应。
- **长文件处理**：对于数 GB 的高清超长音视频，执行重编码或跨格式合并时进度条需要稍作等待，底层正在调用多线程加速处理。
