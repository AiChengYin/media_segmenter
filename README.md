# MediaSegmenter (音视频处理工具)

基于 Python + `customtkinter` 构建的轻量级音视频处理桌面应用，底层依赖 `FFmpeg`。采用了「纯白秩序工坊 · Modern Clean Light」现代轻量化原生视觉设计，0 额外运行开销，秒级极速启动。

## 主要功能

### 1. 音频分割
- 将单个音频文件平均分割为指定数量的片段
- 支持设置前置重叠时间，确保片段之间的平滑过渡

### 2. 音频合并
- 将文件夹内的所有音频片段按顺序合并为一个文件
- 优先无损合并（`-c copy`），失败则自动重新编码

### 3. 视频截取 (新增)
- 选择视频文件后自动显示时长、分辨率、文件大小
- 输入开始/结束时间截取指定区间的视频
- 时间格式支持：`37.30`（秒）或 `00:00:37.30`（时:分:秒）
- 自动校验时间合法性（结束 > 开始，不超过总时长）
- 优先使用 `-c copy` 无损截取，失败自动重编码
- 输出文件名：`原文件名_clip_开始_结束.mp4`
- 支持一键打开输出目录

## 环境要求

- Python 3.8+
- [FFmpeg](https://ffmpeg.org/) 已安装并配置到系统 `PATH`

## 快速开始

```bash
pip install -r requirements.txt
python main.py
```

## 打包为 EXE (Windows)

双击 `build.bat` 即可自动打包，生成的 `MediaSegmenter.exe` 在 `dist` 目录下。

## 注意事项
- 处理大文件时进度条可能需要几秒响应，请耐心等待
- 确保 FFmpeg 已正确安装，否则处理时会报错
